# 词舱 PromptPod v0.14.0

Windows 10 / 11 超轻量贴边 Prompt 一键复制桌面小工具（纯原生 `C++17` + `Win32` + `Direct2D` + `DirectWrite`，MIT 开源）。单文件绿色可执行体量约 `662 KB`，仅依赖 13 个 Windows 系统原生 DLL，零第三方运行时依赖，贴边静止时 `0% CPU` 占用 -- 把最常用的高价值 Prompt 放进屏幕边缘的肌肉记忆里，抬手一触即得。

## 下载与运行

前往 [**GitHub Releases 页面**](https://github.com/Rex-Enough-Better/PromptPod/releases/latest) 下载最新版本：

- **直接运行版**：下载 `PromptPod-0.14.0.exe`（约 `662 KB`），放到任意常用目录双击即用，无需安装，无需管理员权限。
- **压缩包版**：若浏览器拦截裸 `.exe` 下载，可下载 `PromptPod-0.14.0-win64.zip` 解压后双击运行 `PromptPod.exe`。
- **关于 Windows SmartScreen 首次运行提示**：本项目完全开源且仅在本地运行（联网仅用于按需检查 GitHub Releases 更新），因未购买昂贵的商业 EV 代码签名证书，首次运行可能弹出「Windows 已保护你的电脑」提示。你可以点击 **「更多信息」->「仍要运行」**，也可以直接克隆本仓库运行 `.\build.ps1` 在本机从源码独立编译验证。
- **无损在线更新与无缝升级**：已安装 `v0.6.0` 及以上版本可直接在「设置 -> 启动与更新」或托盘右键点击「检查更新」原地升级（点击托盘更新入口会自动滚动定位至更新卡片）；直接双击新版 `.exe` 也会自动优雅接管旧版常驻实例。老用户升级时原有 `%APPDATA%\PromptPod\data.json` 词库与统计完整保留，并支持在设置页「导出备份」的保存类型下拉框中导出旧版 `v2` 兼容备份。

## 核心特性

- **统一物理弹簧动效语言与无障碍 Reduced Motion 全面适配**：
  - 全应用统一采用 4 档临界阻尼弹簧曲线（`Tactile / Snappy / Fluid / Settle`）与无帧率依赖指数逼近：边缘胶囊 `100 ms` 蓄能伸展、展开滑出、底部场景指示条滑动与主题色过渡、右键菜单锚角展开与滑动高亮胶囊、悬停预览气泡贴边锚定二维（宽 / 高 / 纵向位置 / 连接光点）丝滑形变与双层正文交叉淡入淡出、复制成功逐笔矢量打勾、校验拦截阻尼微震、拖拽抬升悬浮与松手归位回弹、设置页分段滑块与弹簧拨片开关、Toast 弹出与 5 秒撤销倒计时细线，以及排行比例条错峰展开均全程支持中途随时打断接续。
  - 自动读取并实时响应 Windows「减少动态效果」（`SPI_GETCLIENTAREAANIMATION` + `WM_SETTINGCHANGE`）：开启后所有位移、缩放、微震、倒计时进度线与逐笔描边立即切换为静态直达与一次性定时清理，确保静止态与 Reduced Motion 均保持 `0% CPU` 零空转功耗。
- **左 / 右边缘自动贴靠、屏边无缝桥接保活、多屏锚点记忆与矮屏自适配**：
  - 拖近屏幕左侧或右侧边缘自动磁吸并收起为 `6 px` 微光胶囊把手（非整数 DPI 下物理右沿满像素对齐）；鼠标滑到屏幕最边缘停顿满 `100 ms` 即以临界阻尼弹簧丝滑滑出，停靠侧提供直达本显示器物理边缘的桥接保活热区，不误收回、跨双屏边界零粘滞。
  - 支持沿边缘上下拖动调节高度，拖离边缘 `> 36 DIP` 正常松手转为悬浮面板并在顶栏提供一键「贴边」微按钮（拖动中断自动回滚）；持久化副屏锚点坐标，极矮工作区（如 `1366 × 768 @ 150%`）下自动固定顶底栏并开启中间槽位滚轮滚动；内置统一收起状态机、显示 / DPI / 休眠唤醒 / 锁屏解锁自动归位与 `3 s` 物理可达性自愈巡检。
- **固定 10 槽位空间肌肉记忆 + 最多 4 组场景多选（默认开启「通用 / 产品」）**：
  - 单屏永远恒定渲染 `01 ~ 10` 共 10 个固定槽位，位置绝不随点击次数乱跳，支持按住上下直接拖拽排序（相邻槽位弹性避让）。
  - 全新启动内置 12 条精选 Prompt 全部收入词舱，默认开启 2 组场景：**「通用」**（装配 `01 ~ 02` 格核心 Agent 指挥 Prompt，空出 `03 ~ 10` 引导录入）与**「产品」**（装配最新 2 条 UX 体验审查与苹果级动效审查 Prompt），并附带零焦点 3 步贴边实操引导（随时可在设置页重播）。
  - 在「设置 -> 贴边面板」通过直观的多选清单自由勾选要显示的场景（预设「通用 / 产品 / 开发 / 写作」，至少保留 1 组、最多全选 4 组；**仅勾选 1 组时自动隐藏底栏回归 `471 DIP` 极简纯 10 槽面板**，勾选 2 ~ 4 组时底部原位以统一圆角卡片展示场景切换按钮 `507 DIP`，支持左键切换、滚轮循环切换与边缘胶囊色调提示；取消勾选完整无损保留编排）。
  - **设置页里外统一的双栏「场景台面工作台」（双向跨栏拖拽）**：设置页、贴边面板场景右键与词舱场景筛选条统一入口打开可缩放双栏工作台 -- 顶部可连续切换 4 组场景，右上角以直观的当前状态胶囊切换「已启用 / 未启用」，并提供重命名与清空（5 秒可撤销）；**左栏 1:1 复刻桌面贴边 10 槽位**（支持上下拖拽排序、点击指定目标槽位、行内编辑 / 移出与完整右键菜单）；**右栏提供原生 IME 关键词搜索与 3 档滑动筛选器**（`未入本场景`、`未分配`、`全部`，每条附带所属场景色标），支持「+ 新建 Prompt」直接装配，更支持**双向跨栏拖拽**：
    - **右 -> 左拖入**：按住右侧待选卡片拽起时，整张卡片自动以临界阻尼弹簧平滑收束为仅含标题的紧凑悬浮胶囊，右侧原空缺在放下前完整保留；拖至左侧任意槽位（空槽放入 / 占槽替换）松手后立即落位，右侧下方卡片丝滑上移补齐空缺（未落入左栏则弹性回落原空缺）。
    - **左 -> 右拖出**：按住左侧已占槽位向右拖入右侧列表区，即刻浮现磨砂红「松手移出」提示层，松手后移出当前台面（正文与使用统计完整保留在词舱，并提供 5 秒就地「撤销移出」）。
- **零焦点抢夺一键复制与极简自解释界面**：
  - 左键轻点实槽直接将完整 Prompt（自动规范化为 Windows CRLF 换行）预分配写入剪贴板、确认成功后使用次数 `+1`、亮起绿光「已复制」反馈并自动缩回（复制后顺手移向其他槽位或按钮会自动取消缩回，绝不抢手；剪贴板被占用写入失败时槽位内联红闪「复制失败，请重试」且不计次、不误收起），原聊天框或编辑器焦点丝毫不变，直接 `Ctrl+V` 即可粘贴。
  - 贴边面板仅在首个空槽与悬停空槽显示「+ 添加 Prompt」，其余空槽保持安静留白；顶栏右上角提供安静的 `···` 菜单入口（再点即收起），所有操作在面板内就地反馈（含只读报错提示与清空场景 5 秒就地「撤销」条），零焦点抢夺。
- **侧边纯穿透全文预览气泡（可开关）**：
  - 鼠标停留在实槽满 `180 ms` 在侧边浮现纯鼠标穿透悬停预览气泡（左右边缘与矮屏自动镜像裁边，引导期间自动避让不遮挡）；在相邻槽位间滑动时内置 `130 ms` 缝隙防闪烁宽限与中段淡出无缝接续，气泡以贴边侧为锚点平滑缩放宽 / 高、滑动连接光点并交叉淡入淡出正文，彻底消除切换闪烁；超长内容底部渐隐并提示左键复制全文、右键编辑。
- **词舱收藏、使用排行、4 分组设置中心与系统托盘 `NOTIFYICON_VERSION_4`**：
  - 面板顶栏 `···`、全区右键、场景按钮右键或系统托盘图标均可直达「词舱管理」「使用排行」「设置」；全 Tab 配备自绘深色极细胶囊滚动条。
  - **词舱收藏**：打开自动聚焦搜索框，搜索框下方提供场景筛选条（`全部 / 各已启用场景 / 未装配`，带实时计数）-- 点击任一场景胶囊立刻按贴边槽位 `01 ~ 10` 顺序过滤展示该场景已装配的 Prompt（纯视图筛选，不篡改桌面贴边面板活跃场景），且**「全部」、各细分场景与「未装配」视图统一支持按住卡片直接拖拽排序**（场景视图下自动保留稀疏空槽间隙并与桌面贴边面板 1:1 实时同步）；右侧提供快捷「编辑台面」弹窗入口，且在该场景视图下「+ 新建 Prompt」与卡片「槽位 ▾」自动对准该场景；支持正文后段命中上下文摘要、无结果快捷「清空搜索 / 搜全部词舱 / 新建此 Prompt」与键盘检索闭环（`Ctrl+F` / `Ctrl+N` / `↑↓` / `Enter` / `Esc` 逐级清空搜索 -> 取消指定槽位 -> 关窗）；卡片高频操作收敛为「复制 / 槽位 / 编辑 / `···`」（副本与危险删除收口至 `···` 及卡片右键菜单）；编辑弹窗支持标题留空自动取正文首行，未保存草稿双按 `Esc` 防误关；删除与清空场景均提供 5 秒可撤销与防误覆盖保护。
  - **数据安全**：默认存储于 `%APPDATA%\PromptPod\data.json`（唯一临时文件 + `FlushFileBuffers` + `MoveFileExW` 原子落盘、启动自动维护 `.bak` 副本、导入前自动创建 `data.pre-import.<时间戳>.json` 快照、导出拦截覆盖现役数据文件、异常损坏时进入只读保护模式并提供一键恢复备份或直接导入备份，危险确认弹窗禁用裸 `Enter` 误确认）。
  - **系统托盘与在线更新**：左键单击 / 双击统一打开词舱管理（可在设置切为贴边面板 Toggle）；移动便携 `.exe` 位置且原文件已不存在时启动自动静默修复开机自启路径；内置 `WinHTTP` + `BCrypt SHA-256` 原生在线更新引擎与脱敏诊断意见反馈弹窗（功能建议自动隐藏诊断项、绝不覆盖剪贴板，绝不含任何 Prompt 内容）。

## 从源码构建

仅需 Windows 10 / 11（`x64`）与 PowerShell 7（`pwsh`）或 Windows PowerShell，克隆仓库后在根目录执行：

```powershell
# 如本机未安装 MinGW-w64 (g++ / windres)，首次附加 -Bootstrap 自动拉取便携编译链至 %LOCALAPPDATA%\PromptPod-Toolchain
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Bootstrap

# 日常增量编译与自检（自动校验版本号同步、< 900 KB 体积、13 个系统原生 DLL 白名单及 --self-test）
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

# 发布打包与二进制本机路径审计（产物暂存至 .tmp/release-stage/v<版本号>）
pwsh -NoProfile -ExecutionPolicy Bypass -File .\release.ps1
```

### 命令行参数

- `--autostart`：静默启动并直接处于贴边收起态（开机自启注册表项默认附带此参数）。
- `--replace`：若同数据目录已有实例正在运行，无论版本号是否变化均先优雅关闭旧实例再无缝接管（可与 `--autostart` 组合实现零打扰静默热替换）。
- `--data-dir <目录路径>`：指定自定义的数据存储目录（用于便携隔离或测试，单实例锁按目录路径独立隔离）。
- `--self-test <临时目录>`：运行无界面确定性全量自检（必须传入非空隔离目录），返回码 `0` 表示全部通过。
