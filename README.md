# 词舱 PromptPod v0.10.0

Windows 10 / 11 超轻量贴边 Prompt 一键复制桌面小工具（纯原生 `C++17` + `Win32` + `Direct2D` + `DirectWrite`，MIT 开源）。单文件绿色可执行体量约 `597 KB`，仅依赖 13 个 Windows 系统原生 DLL，零第三方运行时依赖，贴边静止时 `0% CPU` 占用 -- 把最常用的高价值 Prompt 放进屏幕边缘的肌肉记忆里，抬手一触即得。

## 下载与运行

前往 [**GitHub Releases 页面**](https://github.com/Rex-Enough-Better/PromptPod/releases/latest) 下载最新版本：

- **直接运行版**：下载 `PromptPod-0.10.0.exe`（约 `597 KB`），放到任意常用目录双击即用，无需安装，无需管理员权限。
- **压缩包版**：若浏览器拦截裸 `.exe` 下载，可下载 `PromptPod-0.10.0-win64.zip` 解压后双击运行 `PromptPod.exe`。
- **关于 Windows SmartScreen 首次运行提示**：本项目完全开源且仅在本地运行（联网仅用于按需检查 GitHub Releases 更新），因未购买昂贵的商业 EV 代码签名证书，首次运行可能弹出「Windows 已保护你的电脑」提示。你可以点击 **「更多信息」->「仍要运行」**，也可以直接克隆本仓库运行 `.\build.ps1` 在本机从源码独立编译验证。
- **无损在线更新与无缝升级**：已安装 `v0.6.0` 及以上版本可直接在「设置 -> 启动与更新」或托盘右键点击「检查更新」原地热替换升级；直接双击新版 `.exe` 也会自动优雅接管旧版常驻实例。老用户升级时原有 `%APPDATA%\PromptPod\data.json` 词库与统计完整保留，自动将新增 2 条产品 Prompt 无损补入词舱（仅当第 2 场景为空且未自定义名称时自动初始化为「产品」，绝不覆写已有场景数据），升级前自动留存旧版备份，并支持在设置页随时导出旧版 `v2` 兼容备份。

## 核心特性

- **左 / 右边缘自动贴靠、屏边无缝桥接保活、多屏锚点记忆与矮屏自适配**：
  - 拖近屏幕左侧或右侧边缘自动磁吸并收起为 `6 px` 微光胶囊把手（非整数 DPI 下物理右沿满像素对齐）；鼠标滑到屏幕最边缘停顿满 `100 ms` 即以临界阻尼弹簧丝滑滑出，停靠侧提供直达本显示器物理边缘的桥接保活热区，不误收回、跨双屏边界零粘滞。
  - 支持沿边缘上下拖动调节高度，拖离边缘 `> 36 DIP` 正常松手转为悬浮面板并在顶栏提供一键「贴边」微按钮（拖动中断自动回滚）；持久化副屏锚点坐标，极矮工作区（如 `1366 × 768 @ 150%`）下自动固定顶底栏并开启中间槽位滚轮滚动；内置统一收起状态机、显示 / DPI / 休眠唤醒 / 锁屏解锁自动归位与 `3 s` 物理可达性自愈巡检。
- **固定 10 槽位空间肌肉记忆 + 最多 4 组场景多选（默认开启「通用 / 产品」）**：
  - 单屏永远恒定渲染 `01 ~ 10` 共 10 个固定槽位，位置绝不随点击次数乱跳，支持按住上下直接拖拽排序（相邻槽位弹性避让）。
  - 全新启动内置 12 条精选 Prompt 全部收入词舱，默认开启 2 组场景：**「通用」**（装配 `01 ~ 02` 格核心 Agent 指挥 Prompt，空出 `03 ~ 10` 引导录入）与**「产品」**（装配最新 2 条 UX 体验审查与苹果级动效审查 Prompt），并附带零焦点 3 步贴边实操引导（随时可在设置页重播）。
  - 在「设置 -> 贴边面板」通过直观的多选清单自由勾选要显示的场景（预设「通用 / 产品 / 开发 / 写作」，至少保留 1 组、最多全选 4 组；**仅勾选 1 组时自动隐藏底栏回归 `471 DIP` 极简纯 10 槽面板**，勾选 2 ~ 4 组时底部原位以统一圆角卡片展示场景切换按钮 `507 DIP`，支持左键切换、滚轮循环切换与边缘胶囊色调提示；取消勾选完整无损保留编排）。
  - **设置页直接管理场景提示词**：每个场景卡片自带「重命名」（限 4 个汉字 / 8 个英文字母不截断）与**「配置提示词」**弹窗（亦可在贴边面板右键场景按钮直达）-- 弹窗内可直接通过复选框一键勾选加入 / 取消移出该场景、行内点击「编辑」修改标题与正文，或点击「+ 新建 Prompt」直接新建并自动装配入该场景空槽。
- **零焦点抢夺一键复制**：
  - 左键轻点实槽直接将完整 Prompt（自动规范化为 Windows CRLF 换行）预分配写入剪贴板、确认成功后使用次数 `+1`、亮起绿光「已复制」反馈并自动缩回（剪贴板被占用写入失败时槽位内联红闪「复制失败，请重试」且不计次、不误收起），原聊天框或编辑器焦点丝毫不变，直接 `Ctrl+V` 即可粘贴。
- **侧边纯穿透全文预览气泡（可开关）**：
  - 鼠标停留在实槽满 `180 ms` 在侧边浮现纯鼠标穿透全文预览气泡（左右边缘与矮屏自动镜像裁边），相邻槽位移动零延迟跟随；超长全文底部渐隐并诚实提示总字数与完整复制 / 编辑指引。
- **词舱收藏、使用排行、4 分组设置中心与系统托盘 `NOTIFYICON_VERSION_4`**：
  - 面板底部移除低频管理按钮，右键面板标题栏、空白区、槽位、场景按钮或系统托盘图标均可直达「词舱管理」「使用排行」「设置」；全 Tab 配备自绘深色极细胶囊滚动条。
  - **词舱收藏**：缓存式实时搜索 + 正文后段命中上下文摘要 + 键盘闭环（`Ctrl+F` / `Ctrl+N` / `↑↓` / `Enter` 直复制 / `Esc`）、多场景活跃与跨场景徽标、独立词舱拖拽排序、快速「副本」、5 秒底部 Toast 内联「撤销删除」（跨 4 场景完整恢复）以及可拖拽缩放带实时字数统计的原生编辑弹窗。
  - **数据安全**：默认存储于 `%APPDATA%\PromptPod\data.json`（唯一临时文件 + `FlushFileBuffers` + `MoveFileExW` 原子落盘、启动自动维护 `.bak` 副本、导入前自动创建 `data.pre-import.<时间戳>.json` 快照、导出拦截覆盖现役数据文件、异常损坏时进入只读保护模式并提供一键恢复备份）。
  - **系统托盘与在线更新**：左键单击 / 双击统一打开词舱管理（可在设置切为贴边面板 Toggle）；内置 `WinHTTP` + `BCrypt SHA-256` 原生在线更新引擎与脱敏诊断意见反馈弹窗（绝不含任何 Prompt 内容）。

## 从源码构建

仅需 Windows 10 / 11（`x64`）与 PowerShell 7（`pwsh`）或 Windows PowerShell，克隆仓库后在根目录执行：

```powershell
# 如本机未安装 MinGW-w64 (g++ / windres)，首次附加 -Bootstrap 自动拉取便携编译链至 %LOCALAPPDATA%\PromptPod-Toolchain
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Bootstrap

# 日常增量编译与自检（自动校验版本号同步、< 600 KB 体积、13 个系统原生 DLL 白名单及 --self-test）
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

# 发布打包与二进制本机路径审计（产物暂存至 .tmp/release-stage/v<版本号>）
pwsh -NoProfile -ExecutionPolicy Bypass -File .\release.ps1
```

### 命令行参数

- `--autostart`：静默启动并直接处于贴边收起态（开机自启注册表项默认附带此参数）。
- `--data-dir <目录路径>`：指定自定义的数据存储目录（用于便携隔离或测试，单实例锁按目录路径独立隔离）。
- `--self-test <临时目录>`：运行无界面确定性全量自检（必须传入非空隔离目录），返回码 `0` 表示全部通过。
