# 词舱 PromptPod

Windows 10 / 11 超轻量贴边 Prompt 一键复制桌面小工具。单文件绿色体量仅约 `528 KB`，零外部运行时依赖，贴边静止时 `0% CPU` 占用 -- 把最常用的 10 条高价值 Prompt 放进屏幕边缘的肌肉记忆里，随手一触即得。

## 下载与运行

前往 [**Releases 页面**](https://github.com/Rex-Enough-Better/PromptPod/releases/latest) 下载最新版本：

- **直接运行版**：下载 `PromptPod-0.6.2.exe`（约 `528 KB`），放到任意常用目录双击即用，无需安装，无需管理员权限。
- **压缩包版**：若浏览器拦截裸 `.exe` 下载，可下载 `PromptPod-0.6.2-win64.zip` 解压后双击运行 `PromptPod.exe`。
- **无损在线更新与无缝升级**：已安装 `v0.6.0` 及以上版本可直接在「设置」页或托盘右键点击「检查更新」原地热替换升级；下载新版 `.exe` 直接双击也会自动优雅接管旧版常驻实例，原有 `%APPDATA%\PromptPod\data.json` 词库与统计记录完整保留。
- **首次运行提示**：程序未购买商业代码签名证书，首次启动若弹出「Windows 已保护你的电脑」，点击 **「更多信息」->「仍要运行」** 即可。
- **数据安全独立存储**：所有 Prompt 与统计数据默认保存在 `%APPDATA%\PromptPod\data.json`（启动自动维护 `.bak` 副本，采用唯一临时文件 + 落盘刷写原子替换；导入 JSON 前需二次确认并自动留存 `data.pre-import.<时间戳>.json` 本地快照，导出自动拦截覆盖现役数据文件；异常损坏时自动进入只读保护模式并在词舱顶部提供「一键恢复备份」）。

## 核心特性与快速上手

1. **屏幕左 / 右边缘贴靠、防误触唤醒与物理可达性自愈**
   - 默认贴靠在屏幕右侧边缘，收起后化为一条 `6 px` 宽的微光胶囊把手，避开浏览器滚动条与右上角关闭按钮误触。
   - 鼠标移入把手停顿满 `100 ms` 即以物理弹簧阻尼丝滑滑出；按住把手可沿屏幕边缘上下调节高度，向屏幕中央拉出 `> 36 DIP` 正常松手即可切换为悬浮窗（拖动中断自动回滚，避免误变悬浮），拖近左 / 右屏幕边缘松手自动磁吸贴回。
   - 内置统一自动收起状态机、前台切换 / UIPI 菜单自动关闭、分辨率 / DPI 切换、远程桌面退出、休眠唤醒与锁屏解锁自动归位，以及 `3 s` 零功耗物理可达性与展开态滞留自愈巡检（自动识别置顶组内外部遮挡与分层表面穿透并自愈，遇到全屏游戏 / 视频或自家菜单自动礼让不打架）。

2. **固定 10 槽位肌肉记忆、零焦点复制与拖拽排序**
   - 面板恒定提供 `01` ~ `10` 共 10 个台面槽位（首次启动默认满配内置 10 条深度思考与工程复盘 Prompt），槽位位置绝不随点击次数自动乱跳。
   - **左键轻点复制**：零焦点抢夺（`WS_EX_NOACTIVATE`）将完整 Prompt（自动规范化为 Windows CRLF 换行）写入剪贴板、累计使用次数 `+1`、亮起绿光「已复制」反馈后自动缩回边缘（若剪贴板被占用导致写入失败，槽位内联红闪「复制失败，请重试」且不计次、不误收起）-- 你原来停在 ChatGPT、Claude、Cursor 或编辑器输入框里的光标焦点丝毫不变，直接按 `Ctrl+V` 即可粘贴。
   - **按住上下拖拽排序**：在槽位上按住鼠标左键上下拖动，即可实时调整 10 个槽位的排列顺序。

3. **侧边纯穿透全文预览气泡（可随时关闭）**
   - 鼠标停留在槽位上满 `180 ms`，侧边自动浮现完整 Prompt 全文预览气泡（贴右侧时在左边弹出，贴左侧时自动镜像到右边弹出并自适应裁边），跨槽滑动零延迟跟随；超长全文底部自动平滑渐隐并显示总字数。
   - 气泡采用纯鼠标穿透设计，绝不遮挡底层网页点击；如不需要可在「设置」或托盘右键菜单随时一键关闭。

4. **后台「词舱」无限收藏、一键替换与使用排行榜**
   - **右键槽位快捷菜单**：支持编辑当前 Prompt、新建并放入此格、一键从后台「词舱」待命列表中替换上台面，或将低频条目移回词舱腾空槽位（被换下的 Prompt 及其历史累计次数完整保留在词舱内）。
   - **词舱与排行中心**：点击面板底部「词舱 / 排行 / 设置」按钮即可搜索全部收藏、使用原生中文输入法新建或编辑多行 Prompt（配深色自适应极细胶囊滚动条，支持 `Ctrl+A` 全选、`Ctrl+Enter` 快速保存、落盘失败保留全文与未保存草稿二次确认防误关）、导入导出带二次确认与快照保护的 `JSON` 备份，并通过渐变比例条查看全部 Prompt 的使用频次排行榜。

5. **在线更新、意见反馈、系统托盘与开机自启**
   - **原生在线更新**：内置零第三方依赖的更新引擎，支持 24 小时冷却自动静默检查、下载进度展示、`SHA-256` 完整性校验与原地无损热替换。
   - **问题反馈与交流**：在「设置」页或托盘右键点击「意见反馈」，可一键汇总绝不含任何 Prompt 内容的脱敏环境与诊断摘要并预填跳转 [GitHub Issues](https://github.com/Rex-Enough-Better/PromptPod/issues) ，也可前往作者 X 主页（[@RexAIUniverse](https://x.com/RexAIUniverse)）交流反馈。
   - **单实例与系统托盘**：内置按数据目录隔离的单实例守护（同版本重复双击唤出面板，新版双击自动接管旧版）；在右下角系统托盘图标或面板标题栏右键，即可一键勾选开启「开机自动启动」（登录系统时静默贴边待命，无需管理员权限）、重置贴边位置或一键查看脱敏运行日志（`%APPDATA%\PromptPod\logs\promptpod.log`）。

## 系统要求

- Windows 10（1809 及以上）或 Windows 11（64 位 `x64`），支持多显示器与混合高分屏（Per-Monitor V2 DPI）清晰渲染。
