# 词舱 PromptPod

Windows 10 / 11 超轻量贴边 Prompt 一键复制桌面小工具。单文件绿色体量仅约 `576.5 KB`，零外部运行时依赖，贴边静止时 `0% CPU` 占用 -- 把最常用的 10 条高价值 Prompt 放进屏幕边缘的肌肉记忆里，随手一触即得。

## 下载与运行

前往 [**Releases 页面**](https://github.com/Rex-Enough-Better/PromptPod/releases/latest) 下载最新版本：

- **直接运行版**：下载 `PromptPod-0.8.0.exe`（约 `576.5 KB`），放到任意常用目录双击即用，无需安装，无需管理员权限。
- **压缩包版**：若浏览器拦截裸 `.exe` 下载，可下载 `PromptPod-0.8.0-win64.zip` 解压后双击运行 `PromptPod.exe`。
- **无损在线更新与无缝升级**：已安装 `v0.6.0` 及以上版本可直接在「设置 -> 启动与更新」或托盘右键点击「检查更新」原地热替换升级；下载新版 `.exe` 直接双击也会自动优雅接管旧版常驻实例，原有 `%APPDATA%\PromptPod\data.json` 词库与统计记录完整保留（旧版 `v1 / v2` 升级前自动留存 `data.v2.bak.json` 备份，并支持随时导出旧版 `v2` 兼容备份）。
- **首次运行提示**：程序未购买商业代码签名证书，首次启动若弹出「Windows 已保护你的电脑」，点击 **「更多信息」->「仍要运行」** 即可。
- **数据安全独立存储**：所有 Prompt 与统计数据默认保存在 `%APPDATA%\PromptPod\data.json`（启动自动维护 `.bak` 副本，采用唯一临时文件 + 落盘刷写原子替换；导入 JSON 前需二次确认并自动留存 `data.pre-import.<时间戳>.json` 本地快照，导出自动拦截覆盖现役数据文件；异常损坏时自动进入只读保护模式并在词舱顶部提供「一键恢复备份」）。

## 核心特性与快速上手

1. **首次启动 3 步实操引导与轻装配策略**
   - 全新首次启动内置 10 条深度思考与工程复盘 Prompt 全部收入词舱，台面默认装配 `01 ~ 02` 两格并留空 `03 ~ 10` 方便立即录入你自己的常用提示词（老用户升级完整保留原槽位布局）。
   - 首次手动启动附带轻量零焦点 3 步贴边引导卡（体验零焦点复制 -> 存入第一条 Prompt -> 选贴边方向与开机自启），完成后自动收起并让边缘胶囊呼吸高亮 2 次提示把手位置；随时可在「设置 -> 帮助与反馈」重播。

2. **屏幕左 / 右边缘贴靠、多屏锚点记忆与矮屏自适配**
   - 默认贴靠在屏幕右侧边缘，收起后化为一条 `6 px` 宽的微光胶囊把手，避开浏览器滚动条与右上角关闭按钮误触。
   - 鼠标移入把手停顿满 `100 ms` 即以物理弹簧阻尼丝滑滑出；按住把手可沿屏幕边缘上下调节高度，向屏幕中央拉出 `> 36 DIP` 正常松手即可切换为悬浮窗（顶栏提供一键「贴边」微按钮，拖动中断自动回滚），拖近左 / 右屏幕边缘松手自动磁吸贴回。
   - 持久化副屏锚点坐标（副屏贴边重启不被拉回主屏），极矮工作区（如 `1366 × 768 @ 150%`）下自动固定顶栏与底栏并开启中间槽位滚轮滚动；内置统一自动收起状态机、前台切换 / UIPI 菜单自动关闭、显示 / DPI / 休眠唤醒 / 锁屏解锁自动归位，以及 `3 s` 零功耗物理可达性与展开态滞留自愈巡检。

3. **固定 10 槽位肌肉记忆、可选「多场景台面」、零焦点复制与拖拽排序**
   - 单屏永远恒定提供 `01` ~ `10` 共 10 个台面槽位，槽位位置绝不随点击次数自动乱跳。
   - **可选多场景台面（默认关闭，最多 3 组 × 10 槽位）**：日常保持单组 10 格极致轻巧（0 像素额外高度）；当你同时跨多个固定角色（如「通用 / 思考 / 开发」或自定义写作 / 编程场景）时，可在「设置 -> 贴边面板」开启 `2 组` 或 `3 组` 独立台面。开启后展开面板最下方呈现零焦点分段切换胶囊条（支持左键点击切换、悬停滚轮循环切换、右键场景按钮快速重命名 / 清空槽位 / 打开场景设置），单场景名限 4 个汉字或 8 个英文字母永不截断，收起态边缘微光胶囊随当前场景微调色调提示；跨场景允许共享引用同一条词舱 Prompt，随时关闭或减为 2 组时隐藏场景编排完整无损保留。
   - **左键轻点复制**：零焦点抢夺（`WS_EX_NOACTIVATE`）将完整 Prompt（自动规范化为 Windows CRLF 换行）写入剪贴板、累计使用次数 `+1`、亮起绿光「已复制」反馈后自动缩回边缘（若剪贴板被占用导致写入失败，槽位内联红闪「复制失败，请重试」且不计次、不误收起）-- 你原来停在 ChatGPT、Claude、Cursor 或编辑器输入框里的光标焦点丝毫不变，直接按 `Ctrl+V` 即可粘贴。
   - **按住上下拖拽排序**：在槽位上按住鼠标左键上下拖动，即可实时调整当前场景 10 个槽位的排列顺序。

4. **侧边纯穿透全文预览气泡（可随时关闭）**
   - 鼠标停留在槽位上满 `180 ms`，侧边自动浮现完整 Prompt 全文预览气泡（贴右侧时在左边弹出，贴左侧时自动镜像到右边弹出并自适应矮屏裁边），跨槽滑动零延迟跟随；超长全文底部平滑渐隐并诚实提示总字数及左键复制 / 右键编辑指引。
   - 气泡采用纯鼠标穿透设计，绝不遮挡底层网页点击；如不需要可在「设置」或托盘右键菜单随时一键关闭。

5. **后台「词舱」高效检索、5 秒撤销删除、排行与 4 分组设置中心**
   - **右键槽位快捷菜单**：支持 `↑ / ↓ / Enter / Esc` 键盘导航，可编辑当前 Prompt、新建并放入此格、一键从后台「词舱」按最近使用与频次智能排序快速替换，或将低频条目移回词舱腾空槽位。
   - **词舱收藏与键盘检索直复制**：全 Tab 配备深色极细胶囊滚动条；支持 `Ctrl+F` 聚焦搜索、`Ctrl+N` 新建、`↑ / ↓` 选择、`Enter` 一键复制、`Esc` 先清搜索再关窗、搜索框一键清空 `×`、正文后段命中上下文预览、多场景活跃与跨场景温和副标徽标（如 `开发 · 01`、`+1 场景`）、词舱拖拽排序（独立于台面槽位，支持边缘自动滚屏）、一键创建「副本」与删除 5 秒底部 Toast 内联「撤销删除」（恢复全部场景原槽位）；编辑弹窗支持拖拽缩放、实时字数统计、`Enter` 切正文、`Shift+Tab` 回标题、`Ctrl+Enter` 快速保存与未保存草稿二次确认。
   - **使用排行与 4 分组设置中心**：排行榜动态展示当前场景装配数、支持行内一键「复制」与双击编辑；设置中心重组为「贴边面板」「启动与更新」「数据与备份」「帮助与反馈」4 大分组，支持停靠分段切换与面板归位、多场景台面开关与重命名、导出旧版 `v2` 兼容备份、开机自启旧路径漂移自动检测修复、展开式更新摘要卡与一键复制数据目录路径。

6. **系统托盘 `NOTIFYICON_VERSION_4`、在线更新与意见反馈**
   - **系统托盘统一交互**：升级 `NOTIFYICON_VERSION_4`，左键单击与双击统一为「打开 / 聚焦词舱管理窗口」（可在设置页切换为「切换贴边面板」），彻底消灭双击双重强弹冲突；托盘右键精简为 7 项高频入口。
   - **原生在线更新与意见反馈**：零第三方依赖更新引擎支持 24 小时冷却自动静默检查、`SHA-256` 完整性校验与原地无损热替换；内置「意见反馈」弹窗一键汇总绝不含任何 Prompt 内容的脱敏环境与诊断摘要并预填跳转 [GitHub Issues](https://github.com/Rex-Enough-Better/PromptPod/issues) ，也可前往作者 X 主页（[@RexAIUniverse](https://x.com/RexAIUniverse)）交流反馈。

## 系统要求

- Windows 10（1809 及以上）或 Windows 11（64 位 `x64`），支持多显示器与混合高分屏（Per-Monitor V2 DPI）清晰渲染。
