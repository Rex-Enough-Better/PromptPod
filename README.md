# PromptPod · 词舱

Windows 10 / 11 超轻量贴边 Prompt 一键复制桌面小工具。单文件绿色体量仅约 `341 KB`，零外部运行时依赖，常驻内存约 `7 MB`，贴边静止时 `0% CPU` 占用 -- 把最常用的 10 条高价值 Prompt 放进屏幕边缘的肌肉记忆里，随手一触即得。

## 下载与运行

前往 [**Releases 页面**](https://github.com/Rex-Enough-Better/PromptPod/releases/latest) 下载最新版本：

- **直接运行版**：下载 `PromptPod-0.3.1.exe`（约 `341 KB`），放到任意常用目录双击即用，无需安装，无需管理员权限。
- **压缩包版**：若浏览器拦截裸 `.exe` 下载，可下载 `PromptPod-0.3.1-win64.zip` 解压后双击运行 `PromptPod.exe`。
- **首次运行提示**：程序未购买商业代码签名证书，首次启动若弹出「Windows 已保护你的电脑」，点击 **「更多信息」->「仍要运行」** 即可。
- **数据安全独立存储**：所有 Prompt 与统计数据默认保存在 `%APPDATA%\PromptPod\data.json`（采用临时文件原子替换防断电损坏）；直接替换新版本 `.exe` 即可完成升级，原有词库与统计记录完整保留。

## 核心特性与快速上手

1. **屏幕左 / 右边缘贴靠与防误触唤醒**
   - 默认贴靠在屏幕右侧边缘，收起后化为一条 `6 px` 宽的微光胶囊把手，彻底避开浏览器滚动条与右上角关闭按钮误触。
   - 鼠标移入把手停顿满 `100 ms` 即以物理弹簧阻尼丝滑滑出；按住把手可沿屏幕边缘上下调节高度，向屏幕中央拉出即可切换为普通悬浮窗，拖近左 / 右屏幕边缘松手自动磁吸贴回。

2. **固定 10 槽位肌肉记忆、零焦点复制与拖拽排序**
   - 面板恒定提供 `01` ~ `10` 共 10 个台面槽位（首次启动默认满配内置 10 条深度思考与工程复盘 Prompt），槽位位置绝不随点击次数自动乱跳。
   - **左键轻点复制**：零焦点抢夺（`WS_EX_NOACTIVATE`）将完整 Prompt 写入剪贴板、累计使用次数 `+1`、亮起绿光「已复制」反馈后自动缩回边缘 -- 你原来停在 ChatGPT、Claude、Cursor 或编辑器输入框里的光标焦点丝毫不变，直接按 `Ctrl+V` 即可粘贴。
   - **按住上下拖拽排序**：在槽位上按住鼠标左键上下拖动，即可实时调整 10 个槽位的排列顺序。

3. **侧边纯穿透全文预览气泡（可随时关闭）**
   - 鼠标停留在槽位上满 `180 ms`，侧边自动浮现完整 Prompt 全文预览气泡（贴右侧时在左边弹出，贴左侧时自动镜像到右边弹出），跨槽滑动零延迟跟随；超长全文底部自动平滑渐隐并显示总字数。
   - 气泡采用纯鼠标穿透设计，绝不遮挡底层网页点击；如不需要可在「设置」或托盘右键菜单随时一键关闭。

4. **后台「词舱」无限收藏、一键替换与使用排行榜**
   - **右键槽位快捷菜单**：支持编辑当前 Prompt、新建并放入此格、一键从后台「词舱」待命列表中替换上台面，或将低频条目移回词舱腾空槽位（被换下的 Prompt 及其历史累计次数完整保留在词舱内）。
   - **词舱与排行中心**：点击面板底部「词舱 / 排行 / 设置」按钮即可搜索全部收藏、使用原生中文输入法新建或编辑多行 Prompt（支持 `Ctrl+Enter` 快速保存）、导入导出 `JSON` 备份，并通过渐变比例条查看全部 Prompt 的使用频次排行榜。

5. **系统托盘与开机自动启动**
   - 内置单实例守护（重复双击自动展开唤醒已有实例）；在右下角系统托盘图标或面板标题栏右键，即可一键勾选开启「开机自动启动」（登录系统时静默贴边待命，无需管理员权限）或重置贴边位置。

## 系统要求

- Windows 10（1809 及以上）或 Windows 11（64 位 `x64`），支持多显示器与高分屏（Per-Monitor V2 DPI）清晰渲染。
